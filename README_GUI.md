#  Калькулятор на Tkinter

Простой графический калькулятор на Python с использованием стандартной библиотеки `tkinter`.

## Возможности

- Базовые арифметические операции: `+`, `-`, `*`, `/`
- Ввод десятичных чисел (кнопка `.`)
- Удаление последнего символа (`←`)
- Полная очистка поля (`AC`)
- Обработка ошибок (например, деление на ноль)
- Розовый интерфейс с сеточной компоновкой кнопок

## Требования

- Python 3.x
- Tkinter (входит в стандартную поставку Python; на Linux может потребоваться установка)
