# Консольный калькулятор на Python

Простой консольный калькулятор, написанный на языке Python 3.10+. Программа работает в пошаговом режиме, запрашивая у пользователя числа и желаемую арифметическую операцию, а также обрабатывает ошибочный ввод.

## Функциональность

Программа поддерживает следующие операции:
*   Сложение: `+`
*   Вычитание: `-`
*   Умножение: `*` или `×`
*   Деление: `/` или `÷`
*   Возведение в степень: `^` или `**`
*   Остаток от деления: `%`

## Особенности реализации

*   Калькулятор корректно обрабатывает деление на ноль и критические переполнения при возведении в степень, не завершая работу аварийно.
*   Программа отклоняет нечисловой ввод и неизвестные знаки операций, предлагая пользователю повторить попытку..
*   Выйти из приложения можно на любом этапе ввода, набрав команду `q` или `exit`.


## Запуск приложения
Запустите калькулятор из терминала/командной строки, находясь в папке с файлом `calculator.py`:


python calculator.py


## Пример использования

```
КОНСОЛЬНЫЙ КАЛЬКУЛЯТОР 
Инструкция:
1. Вводите данные пошагово (число, операция, число).
2. Поддерживаемые операции: +, -, *, ×, /, ÷, ^, **, %
3. Для выхода из программы введите 'exit' или 'q' на любом шаге. 
--------------------------------------------------

--- Новое вычисление ---
Введите первое число: 5
Введите операцию (+, -, *, /, ^, %): *
Введите второе число: 5
Результат: 25

--- Новое вычисление ---
Введите первое число: й
Ошибка ввода! Пожалуйста, введите корректное число или 'q' для выхода.
Введите первое число: q

Программа завершена.
```
